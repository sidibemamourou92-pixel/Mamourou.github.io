Ventilateur Automatique Intelligent

Système de ventilation régulé par microcontrôleur Arduino, utilisant un capteur de température DHT11, un relais et un écran LCD pour l'affichage en temps réel.

  • Arduino Uno
  • Capteur DHT11
  • Écran LCD 16x2
  • Relais 5V

Fonctionnalités :

  • Mesure de température en temps réel
  • Contrôle automatique du ventilateur
  • Affichage des données sur LCD
  • Seuil de température ajustable

Robot Araignée (12 Servomoteurs)

Robot marcheur biomimétique à 12 degrés de liberté. Contrôle précis des servomoteurs pour reproduire la démarche d'une araignée avec synchronisation des mouvements.

Technologies utilisées :

  • Arduino Mega 2560
  • Servomoteurs MG996R (x12)
  • PCA9685 (contrôleur PWM)
  • Structure 3D imprimée

Fonctionnalités :

  • 12 degrés de liberté
  • Cinématique inverse
  • Plusieurs modes de marche
  • Contrôle via application mobile

Voiture Télécommandée & Autonome

Voiture robotisée avec double mode : télécommande manuelle et navigation autonome avec capteurs à ultrasons pour l'évitement d'obstacles en temps réel.

Fonctionnalités :

  • Mode télécommandé via smartphone
  • Mode autonome avec évitement
  • Détection d'obstacles à 30cm
  • Vitesse variable
